# Galactic Federation Corps

Recruitment website for the Galactic Federation Corps, a Helldivers Discord community.

Discord: https://discord.gg/rEmcNk9WT

The whole site is one static file, `index.html`. There is no build step.

## Preview locally

    python3 -m http.server

Then open http://localhost:8000.

## Put it online (GitHub Pages)

1. Open the repository on GitHub, then Settings, then Pages.
2. Under "Build and deployment", choose "Deploy from a branch".
3. Select the `master` branch and the `/ (root)` folder, then Save.
4. After a minute the site appears at `https://<your-username>.github.io/<repository-name>/`. Share that link.

## Edit

- Discord link: `DISCORD_URL` near the bottom of `index.html`.
- Text, ranks, ticker bulletins and loadout lists: edit them directly in `index.html`.
